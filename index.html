Approach

How the work gets done

  1. 01

    Specify

    Pin the problem down precisely and write the invariants a correct answer has to keep — before any code exists.

  2. 02

    Agents build

    Claude Code and Codex write most of the code: 2,673 sessions across 3 machines so far.

  3. 03

    Audit

    Check what comes back adversarially — audit harnesses, cross-checks against independent sources, tests — so a wrong total never looks like a right one.
